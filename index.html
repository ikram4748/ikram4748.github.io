CNN vs Vision Transformer on imbalanced FER2013

  • Compared an enhanced ResEmoteNet CNN with squeeze-and-excitation blocks against ViT-Base/16 on FER2013 (35,887 images, 7 classes, 16.5:1 class ratio), with class-balanced focal loss, two-stage training and CutMix, Mixup and RandAugment.
  • Showed that ViT self-attention avoids minority-class collapse (64.9% vs 0% accuracy on Disgust), while the CNN with channel attention was stronger overall on low-resolution faces.

Data Analyst Agent

Ask a database a question in plain English. The agent links the schema, writes SQL, runs it read-only, catches silent mistakes and fixes its own query.

What I built and measured

  • Built a self-correcting text-to-SQL agent: local-embedding schema linking, a two-layer read-only SQL guard, a literal-value check that catches silent zero-result errors, and a bounded fix loop driven by database feedback.
  • Raised execution accuracy on 150 held-out BIRD questions from 60.7% (one-shot baseline, same model) to 66.7% (+6.0 points, 95% CI +1.3 to +11.3) at 1.09 LLM calls per question; tuned on a separate dev split after error analysis of 48 failures.
  • Found and fixed a measurement bug in which rate-limit fallback silently mixed three models across benchmark variants.
